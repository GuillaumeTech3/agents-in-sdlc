**[GitHub Copilot CLI](https://docs.github.com/copilot/concepts/agents/about-copilot-cli)** incorpora GitHub Copilot a tu terminal como asistente de programación con agentes. Explora bases de código, genera código, ejecuta comandos y se conecta a herramientas externas, todo desde la línea de comandos, para que puedas mantener el flujo sin cambiar a un editor gráfico.

El taller sigue un flujo de trabajo continuo en Tailspin Toys: prepararás el proyecto en GitHub Codespaces, instalarás Copilot CLI y añadirás una pequeña mejora de valoraciones con estrellas antes de crear tu primer pull request. Después, empezarás con una incidencia de filtrado, planificarás el enfoque, implementarás la funcionalidad y la revisarás. Actualizarás las instrucciones del repositorio, personalizarás una skill de comprobaciones de calidad, probarás el comportamiento con Playwright MCP y crearás un agente de QA. Por último, revisarás el cambio completo, usarás Agent Merge para el pull request de filtrado y explorarás comandos de barra útiles. También puedes seguir una [serie opcional de tres módulos con GitHub Copilot CLI y Foundry][foundry].

Para mantener el taller centrado, crearás dos pull requests: uno para las valoraciones con estrellas y otro para el filtrado, que incluirá las actualizaciones de instrucciones, skill, perfil de QA y pruebas. El trabajo de filtrado y calidad comparte una conversación y una rama para que puedas aprovechar lo aprendido a medida que exploras cada herramienta.

## Requisitos previos

Antes de asistir a este taller, asegúrate de tener:

- [ ] Una cuenta de GitHub con un plan activo de **Copilot Student, Pro, Pro+, Business o Enterprise**
- [ ] Permiso para crear un repositorio y un codespace
- [ ] Conocimientos básicos del terminal o la línea de comandos

> [!TIP]
> ¿No tienes un plan de pago? Los estudiantes verificados pueden obtener GitHub Copilot gratis a través de [GitHub Education][callout-student-plan-education]. El plan **Copilot Student** incluye las funciones de agente, MCP, revisión de código y Copilot CLI que utiliza este taller.

[callout-student-plan-education]: https://github.com/education/students

> [!NOTE]
> Si usas Copilot Business o Copilot Enterprise, asegúrate de que tu administrador haya habilitado Copilot CLI.
